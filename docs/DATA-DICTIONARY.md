# 计量定义

claim_id唯一；item为清单编码，支持钢筋与001等别名。period为YYYY-MM。累计数量按t或m³保存，当前周期工程量=本次累计-前期已审累计。previous_revisions参数可指定更正后的前审数量，重新计算形成不同批次，不覆盖旧证据。

C0原始价100元，C1自2026-11生效为120元，DRAFT未批准不可结算。负进度必须reversal=approved作为已批冲回标记。扣留质保金5%、预付款扣回10%分别按分量化，净额=本期总额-质保金-预付款扣回，负进度同步冲回扣留。reported为原申报净额，差异=复算净额-reported。

业务ID和超大整数按文本保形；Decimal参与数量金额计算，对外序列化为字符串。哨兵集合定义在app/values.py，缺失值不能当零。所有时间带UTC偏移，先转UTC比较，业务日按指定地区划分。区间统一[start,end)。重复业务键按规范行序裁决（清单别名归一后逐字段比较），与投递行序无关：采纳行与隔离冲突行在换序重投后保持一致；完全相同行计重复。空文件、全空白、仅表头分开拒绝。

## 投递、内容与封存身份

- 投递摘要：原始文件字节加参数，重试同一投递保持同一摘要，只留一份原件。
- 内容摘要：剔除物理行号等传输痕迹后按规范行序计算的业务内容摘要，与文件字节和行顺序无关。
- 月末封存编号：`MS-<YYYYMM>-<内容摘要前8位>`，月份取申报周期最晚月份。同一组申报内容永远得到同一编号；内容不同则编号不同。
- 封存版本：同一编号下按证据内容追加版本。复核状态变化或新原件到达产生新版本，旧版本证据始终可导出；同一状态重复封存复用已有版本。
- 中断恢复：封存先落 pending 意图再定稿，失败时旧版 sealed 证据不受影响；恢复丢弃 pending 并从已有版本续号，不会从 1 重来。

运行清单包括输入sha256、规则版本、参数、生成时刻与耗时。源行编号以CSV解析器的物理结束行号表示，引号内换行不增加记录数。输入超过4MB返回413，非法表头和类型返回422，失效版本复核返回409。
